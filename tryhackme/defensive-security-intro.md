# TryHackMe — Defensive Security Intro

## Overview

Completed the TryHackMe "Defensive Security Intro" room.

This room introduced the fundamentals of defensive security and provided hands-on experience investigating suspicious activity in a simulated security monitoring environment.

## What I Did

* Learned the purpose of defensive security.
* Reviewed suspicious activity using a simulated monitoring dashboard.
* Identified the source of suspicious traffic.
* Investigated URL discovery attempts made by an attacker.
* Identified the attacker's activity.
* Practiced containing the attack by blocking the attacker's IP address.
* Worked with security controls used to help stop ongoing attacks.

## What I Learned

* Defensive security focuses on detecting, investigating, and responding to attacks.
* Security monitoring helps identify suspicious activity.
* Logs and alerts can provide information about attacker behavior.
* Containment is an important part of incident response.
* Blocking malicious traffic can help prevent an attacker from continuing an attack.
