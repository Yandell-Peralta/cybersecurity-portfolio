# TryHackMe — Junior Security Analyst Intro

## Overview

Completed the TryHackMe "Junior Security Analyst Intro" room.

This room introduced the role of a Junior Security Analyst and provided hands-on experience with security monitoring, alert investigation, and incident response.

## What I Did

- Learned about the responsibilities of a Junior Security Analyst.
- Learned how a Security Operations Center (SOC) operates.
- Reviewed security alerts in a simulated SOC environment.
- Investigated suspicious activity and identified a malicious IP address.
- Escalated a security alert to the appropriate team member.
- Practiced blocking malicious traffic using a firewall.
- Learned how analysts work with other SOC roles during security incidents.

## What I Learned

- SOC analysts monitor and investigate security alerts.
- Security alerts need to be investigated and prioritized.
- Analysts may escalate more serious incidents to other security teams.
- Firewalls can be used to block malicious network traffic.
- SOC analysts work as part of a larger security team.
- Communication and teamwork are important during security incidents.
